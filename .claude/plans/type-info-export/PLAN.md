## Notes

This is a **research/investigation plan**, not a feature implementation plan.
Each phase's deliverable is a markdown document in `analysis/findings/` or
`research/results/`, not production code (except R-4 if pursued).

The plan is **non-blocking** for the Quine-to-Roc port. If this investigation
stalls or concludes without a contribution, Quine proceeds with the hybrid
approach (explicit public signatures, inferred private) unchanged.
